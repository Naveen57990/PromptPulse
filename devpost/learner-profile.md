# Learner Profile

## Initial Idea
PromptPulse Studio: A local-first prompt regression, schema validation, and token economy workbench for AI engineers and developers. Enables side-by-side prompt diffing, automated evaluation across custom test cases, token cost projection across multiple LLM providers, and regression detection before shipping prompts to production.

## Demonstrated Technical and Agent Experience
Experienced full-stack software engineer specializing in developer tooling, schema validation, and deterministic evaluation workflows.
Evidence: "I want an autonomous, production-grade developer tool with bespoke UI, automated tests, local execution, and zero bloat."

## Planning-Workflow Experience
Familiar with spec-driven development, PRD structuring, test-driven validation, and iterative slice delivery. Prefers concise, high-velocity execution with rigorous verification checkpoints.

## Desired Learning Outcome
Mastering local deterministic evaluation frameworks for generative AI applications—specifically isolating prompt regressions, measuring schema compliance, and profiling multi-model token economics locally without remote API locks.

## Learning Moments
- Designed local heuristic evaluation criteria isolating schema drift, length deviation, and variable interpolation.
- Structured test suites with automated pytest assertions running in sub-millisecond execution cycles.

## Interests, Inspirations, and Goals
- Inspiration: Professional developer tools like Postman, Vitest, and Raycast that prioritize instant tactile feedback, local speed, and keyboard ergonomics.
- Goals: Deliver a zero-setup open-source workbench that any developer or judge can immediately test with their own prompts.

## Vocabulary and Concepts Likely to Need Explanation
- Well understood: Prompt templates, AST parsing, tokenization algorithms, schema validation, and continuous integration.
- Focus: Clear plain-English visualization of regression deltas and cost comparisons.

## Collaboration and Communication Preferences
Concise, action-oriented execution; fast mode with mechanical verification at every slice boundary.

## Areas Where the Learner Wants Ownership
Overall product design, tactile UI/UX aesthetics, color system, and prompt evaluation metrics.

## Likely Support Needs
Automating high-resolution video capture, neural voiceover synthesis, and edge deployment automation.
